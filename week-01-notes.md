# week 01 notes
## what is automation testing??
*Automation testing is the process of using software tools and scripts to execute test cases automatically instead of performing them manually.
## Why automation testing matters??
* Saves time by reducing repetitive manual work
* Improves test accuracy and reliability
* Helps detect defects early
* Support continuous testing in Agile teams
* Allows tests to run repeatedly after every change 

## What does the team automate??
* Regression tests
* Performance tests
* Data driven tests
* Integration , API , Unit tests
